# Startup Pitch Deck — PLP 12-Slide First Draft

This repository contains the first content draft for the PLP startup pitch-deck assignment.

## Important
The Canva template link provided for the assignment could not be programmatically opened from this environment, so this draft follows the 12-slide structure described in the assignment materials: Problem, Solution, Product, Target Market, Market Size, Competitors, Competitive Advantage, Traction & Roadmap, Revenue Model, Go-to-Market, Ask, and Team.

Replace the bracketed fields with your actual startup information before submitting.

- `canva-content-checklist.md` — quick transfer/checklist for building the deck in Canva
